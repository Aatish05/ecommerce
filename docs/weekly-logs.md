## Strong contribution wording examples

Use detailed statements like:

- Implemented PHP session authentication and protected admin pages with role-based authorization.
- Added server-side validation for registration, checkout, contact, and admin product forms.
- Created MySQL schema with foreign keys linking users, orders, order items, products, and categories.
- Built product CRUD operations using PDO prepared statements to prevent SQL injection.
- Improved accessibility by adding labels, alt text, semantic headings, and keyboard-friendly controls.

Avoid vague statements like:

- Worked on website.
- Helped with coding.
- Did report.
