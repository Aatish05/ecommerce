# EcoTech Electronics Simple Wireframes

These wireframes show the basic layout plan for the electronics e-commerce website. The low-fidelity version focuses on structure. The high-fidelity version explains the final visual design.

## Editable image files

Four editable SVG image files are included:

- `docs/wireframe-images/low-fidelity-flow-10-pages.svg` - main low-fidelity flow with 10 pages
- `docs/wireframe-images/high-fidelity-flow-10-pages.svg` - main high-fidelity flow with 10 pages
- `docs/wireframe-images/low-fidelity-wireframe.svg` - simple overview version
- `docs/wireframe-images/high-fidelity-wireframe.svg` - simple overview version

These can be opened in a browser, inserted into the report as images, or imported into Figma as editable vector files.

The main 10-page flow covers:

1. Homepage
2. Products page
3. Product detail page
4. Cart
5. Checkout
6. Login/Register
7. User order history
8. Admin dashboard
9. Admin product management
10. Vendor dashboard/panel

## High-fidelity design

The final design uses a clean Bootstrap layout with a green electronics/sustainability theme.

### Main design choices

- **Colour theme:** green, white, dark grey
- **Layout:** responsive Bootstrap grid
- **Navigation:** sticky top navigation bar
- **Product display:** card layout with image, price, stock, and buttons
- **Admin panel:** sidebar menu, dashboard cards, tables, and sales graph
- **Vendor panel:** similar dashboard layout but only for the vendor's own products and revenue
- **Accessibility:** labels, alt text, readable contrast, and clear headings

## Summary

The wireframes show a simple, user-friendly e-commerce structure. Customers can browse products and checkout easily, admins can manage the full website, and vendors can add products and view their own sales.
